# Româna — румынский для русскоязычных

Приложение для изучения румынского языка с нуля, для тех, кто говорит
по-русски. Первая цель — уровень A1.

**Зачем.** Курс румынского у Duolingo существует только с английского:
русскоязычному приходится учить язык через третий. Это приложение
объясняет всё от русского напрямую.

## Файлы

| Файл | Что это |
|---|---|
| `index.html` | само приложение, один файл, открывается в браузере |
| `PROJECT.md` | решения по проекту, статус, что дальше |
| `course-a1.md` | программа курса A1 — черновик на проверку носителям |

## Что уже работает

- Путь из четырёх юнитов секции 1 с грамматическими заметками
- Пять типов упражнений, повторение пройденного
- Сохранение прогресса и стрик
- Словарь с поиском: слова курса, 5 бытовых тем (цвета, числа, дни недели,
  месяцы и времена года, семья) и 13 профессиональных наборов
  (общепит, документы, медицина, стройка, логистика, школа, банк и другие)

## Чего пока нет

- Аккаунтов: прогресс лежит на устройстве и не переносится
- Настоящего аудио: пока синтез речи браузера
- Секций 2–10 курса
- Проверки материала носителями языка

## Как запустить

Открыть `index.html` в браузере. Ничего устанавливать не нужно.
