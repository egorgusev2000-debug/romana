# Româna — румынский для русскоязычных

Приложение для изучения румынского языка с нуля, для тех, кто говорит
по-русски. Первая цель — уровень A1.

**Зачем.** Курс румынского у Duolingo существует только с английского:
русскоязычному приходится учить язык через третий. Это приложение
объясняет всё от русского напрямую.

## Файлы

| Файл | Что это |
|---|---|
| `index.html` | само приложение, один файл, открывается в браузере |
| `PROJECT.md` | решения по проекту, статус, что дальше |
| `course-a1.md` | программа курса A1 — черновик на проверку носителям |

## Что уже работает

Внизу экрана — пять разделов:

- **Курс** — путь-дорожка из 40 юнитов, все 11 секций уровня A1
  (от первых фраз до города и врача), с грамматическими заметками,
  семь типов упражнений, включая «Найди пары», «как читается» и
  «циферблат → фраза», повторение пройденного. Звук на ответ (можно
  выключить), анимация и конфетти на результате. В секции 8 (проба,
  только там) — короткая сценка с диалогом и переводом по нажатию
  перед каждым уроком, и завершающая «История» с вопросами
  «верно/неверно».
- **Словарь** — слова курса, с поиском.
- **Наборы** — 13 бытовых тем (цвета, числа 0–100, дни недели, месяцы
  и времена года, семья, вещи вокруг, время и часы, профессии, дом и
  мебель, люди вокруг, деньги и документы, продукты, одежда и обувь)
  и 13 профессиональных наборов (общепит, документы, медицина,
  стройка, логистика, школа, банк и другие).
- **Тренировка** — Блиц (перевод на скорость за 60 секунд, лучший
  результат запоминается), Аудирование (голос браузера произносит
  слово или фразу, нужно выбрать перевод), Работа над ошибками
  (повтор того, на что ответили неверно). Всё — только по уже
  пройденному материалу.
- **Прогресс** — стрик, сколько юнитов пройдено из 40, сколько слов
  курса выучено.

Сохранение прогресса и стрик — на устройстве, не сбрасываются.

## Чего пока нет

- Аккаунтов: прогресс лежит на устройстве и не переносится
- Настоящего аудио: пока синтез речи браузера
- Проверки материала носителями языка
- Уровня A2 и выше (программа A1 построена целиком)

## Как запустить

Открыть `index.html` в браузере. Ничего устанавливать не нужно.
