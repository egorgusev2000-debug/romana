## Что за приложение

Приложение для изучения румынского языка русскоязычными с нуля.
Формат — короткие уроки в духе Duolingo: слово или фраза, упражнение, мгновенная
обратная связь, повторение пройденного.

**Первая цель — уровень A1.** Не «весь язык». Примерно 500–700 слов,
базовая грамматика, бытовые темы. Всё остальное — после.

**Порядок платформ:** сначала веб, потом мобильное приложение.

## Кто над ним работает

| Роль | Кто | Чем занимается |
|---|---|---|
| Автор проекта | владелец | решения, приоритеты, запуск задач |
| Разработка | Claude Code | код |
| Содержание курса | носители румынского (несколько человек) | проверка материала |
| Аудио | уточняется | озвучка слов и фраз |

Нужен один основной человек, отвечающий за содержание. Остальные помогают.
Иначе в курсе появится разнобой в стиле и регистре речи.

---

## Как устроена работа

Разработка ведётся с iPad, своего компьютера нет.

- Код живёт в GitHub-репозитории.
- Работа идёт через облачные сессии Claude Code: `claude.ai/code` в браузере
  или вкладка **Code** в приложении Claude. Локальная машина не нужна.
- Обычный чат с Claude — для методики курса, планирования и обсуждений,
  которым не нужен доступ к коду.

Внешняя клавиатура к iPad обязательна.

## Принятые решения

**Модель нужна не везде.**
Уроки, прогресс, повторения, проверка выбора из вариантов — обычный код и база
данных. LLM подключается только там, где без него нельзя. Это главное решение
по бюджету.

**Распределение моделей:**

| Задача | Модель | Почему |
|---|---|---|
| Генерация материала курса | Opus 5 или Sonnet 5 через Batch API | не в реальном времени, скидка 50%, результат кладётся в базу один раз |
| Проверка свободного ввода перевода | Haiku 4.5 | горячий путь, много вызовов, задача простая |
| Разговорная практика (если будет) | Sonnet 5 | нужен диалог живого качества |

Opus в рантайме не используется.

**Материал проверяется по ходу, а не в конце.**
Ошибки генерации почти всегда системные. Носители проверяют первые ~50 заданий
каждой партии: мало ошибок — партия принимается, много — правится промпт и
генерируется заново. Полное прохождение курса живыми людьми — в самом конце.

**Особенности пары «русский → румынский», которые надо учесть в программе:**

- славянский пласт лексики — многие слова даются русскоязычному почти даром,
  на этом стоит строить первые уроки;
- артикль в конце слова (`om` → `omul`) — непривычно, вводить рано;
- средний род;
- падежи;
- диакритика `ă â î ș ț` — нужна поддержка ввода.
